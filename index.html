Parent Portal

Parents view a read-only Fee Status / Attendance / Notices dashboard in a separate parent-portal.html file. Share the School ID below with whoever sets it up (entered once, on first launch). Anything you update here — fees, attendance, notices — appears there instantly.

One-time setup needed for this to work: in the Firebase Console, enable Anonymous sign-in (Authentication → Sign-in method) and set up Firestore rules covering the schools/{uid} document AND its students, attendance, requests, passLookup and classRosters subcollections. See the comment above firebaseConfig near the bottom of this file for the exact rules to paste — parents can only ever fetch one exact document at a time (their child's, via their Access Pass), never browse the full list.

IDPS AI Assistant

Connect any AI provider to power the chat assistant in the bottom-right corner. Your key is stored only in this browser's local storage — it is never synced to Firestore or committed anywhere — but it IS visible in this browser's Network tab (DevTools) whenever a message is sent, like any client-side app calling an AI API directly. Don't use a key with billing limits you're not comfortable exposing on a shared device.

Works with any provider that speaks the OpenAI chat-completions format — Groq, OpenRouter, Mistral, Together AI, a local Ollama server, etc.

Data Management
